# Md Sourov Hasan Portfolio

## Goal
Build a polished single-page portfolio using the uploaded content and the shared Dribbble page as the visual benchmark, while keeping Sourov’s experience accurate and student-focused.

## What I’ll build
- Sticky navigation with smooth section links and a saved light/dark preference.
- A strong introductory area with Sourov’s name, career direction, contact links, and a professional portrait treatment.
- About, education, skills, services, featured projects, technical journey, current focus, contact, and footer sections.
- Responsive mobile navigation, accessible controls, subtle motion, and reduced-motion support.
- A working contact form that validates fields and opens a prefilled email draft, since no form service is connected.
- Unique portfolio metadata for search and sharing.

## Visual direction
- Adapt the reference’s editorial, high-contrast portfolio feel rather than copying it literally.
- Use a dark architectural canvas, warm light surfaces, vivid lime accents, bold display typography, crisp grid lines, and restrained glass effects.
- Use architecture diagrams, numbered project panels, capability chips, and timeline motifs to reinforce the system-design identity.

## Technical details
- Keep the experience on `/` with semantic sections because the brief explicitly requests smooth scrolling.
- Build reusable React sections and use the existing interface components and icons.
- Keep all visual values in the shared design system and avoid adding a database or external service.
